# Getting started

DaisyBlazor is a [Tailwind CSS v4](https://tailwindcss.com) + [daisyUI v5](https://daisyui.com)
component kit for Blazor (Server **or** WebAssembly). This guide adds it to an existing app. To start
from scratch, use the template instead:

```bash
dotnet new install DaisyBlazor.Templates
dotnet new daisyblazor -o MyApp
```

## 1. Add the package

```bash
dotnet add package DaisyBlazor.Components
# optional: dependency-free SVG charts
dotnet add package DaisyBlazor.Charts
```

## 2. Turn on the CSS build

DaisyBlazor styles are generated by Tailwind at build time — no Node or npm needed. The package ships
the preset (with daisyUI bundled) and an MSBuild target that runs the Tailwind standalone CLI. Enable it
in the web project's `.csproj`:

```xml
<PropertyGroup>
  <DaisyBlazorBuildCss>true</DaisyBlazorBuildCss>
</PropertyGroup>
```

## 3. Author your stylesheet

Create `Styles/main.css`:

```css
@import "tailwindcss";
@import "../obj/daisyblazor/preset.css";  /* daisyUI + themes + class safelist, copied by the package */

/* Your own markup. The packaged components need no glob: the preset safelists their classes. */
@source "./Components/**/*.{razor,cs}";
```

> Use `preset-core.css` instead to skip the 35 built-in daisyUI themes. See
> [CSS preset](/daisyblazor/css-preset/) for the details and the MSBuild properties.

`dotnet build` compiles it to `wwwroot/css/app.css` (the first build downloads the Tailwind CLI
once). Link the output in your host page
(`App.razor` / `index.html`):

```html
<link rel="stylesheet" href="@Assets["css/app.css"]" />
<!-- Icons rendered by the Icon component + Icons.Material.* -->
<link rel="stylesheet"
      href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined" />
<!-- Applies the saved/OS theme before first paint (no flash, works on static SSR pages) -->
<script src="_content/DaisyBlazor.Components/theme-init.js"></script>
```

## 4. Register services

`Program.cs`:

```csharp
using DaisyBlazor;

builder.Services.AddDaisyBlazor();   // ISnackbar + IDialogService
```

`_Imports.razor`:

```razor
@using DaisyBlazor
@using DaisyBlazor.Theming
```

## 5. Wrap your layout in the theme provider + hosts

In your main layout, add the `ThemeProvider` (dark mode + theme switching) and the dialog/snackbar
hosts so services can render into them:

```razor
<ThemeProvider>
    @Body

    <DialogProvider />
    <SnackbarProvider />
</ThemeProvider>
```

## 6. Use components

```razor
<Card>
    <CardContent>
        <h2 class="card-title">Hello DaisyBlazor</h2>
        <p>60+ daisyUI components with a MudBlazor-compatible API.</p>
        <Tabs>
            <Tab Title="One">First panel</Tab>
            <Tab Title="Two">Second panel</Tab>
        </Tabs>
        <CardActions>
            <Button Color="Color.Primary" StartIcon="@Icons.Material.Filled.Check">OK</Button>
        </CardActions>
    </CardContent>
</Card>
```
